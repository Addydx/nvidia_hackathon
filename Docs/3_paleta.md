## Paleta de colores

Inspirada en NVIDIA. Tema oscuro para móvil y escritorio.

| Color | Código | Uso |
|---|---|---|
| Negro carbón | `#121212` | Fondo principal y texto sobre botones verdes |
| Verde lima | `#76B900` | Acciones principales y navegación activa |
| Rojo coral | `#FF6B6B` | Errores y avisos de faltante o sobrante |

### Verdes de apoyo

- `#76B900` → `#A3E635` — Degradado para botones principales.
- `#2E5A1C` — Fondo de indicadores como «Caja abierta».

### Grises

- `#222222` — Tarjetas.
- `#353535` — Bordes.
- `#F5F5F5` — Texto principal.
- `#B8B8B8` — Texto secundario.

### Estados de caja

- Verde para «La caja cuadra».
- Rojo para «Faltan $5» o «Sobran $5».
- Acompaña cada estado con texto para que se entienda sin depender del color.
